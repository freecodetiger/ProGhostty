# R1.2 SPEC：display-link 独占偏移的平滑滚动（方案 X）

状态：可执行方案 · 基于 R1.1（`6ca6c78`）已提交的渲染地基
前置已就绪：24 行 overscan 缓冲（VT+纹理）、composite band 平移、SmoothScrollEngine 纯逻辑+单测（未接线）
上次失败复盘：见 `.claude/R1_SCROLL_BUGS.md`（offset 双写者竞态 / abort thrash / 每帧同步 commit）

---

## 0. 一句话

滚动手势/惯性期间，**display-link 每帧只把 `viewport.visualOffsetY` 设为 `engine.position`（在 24 行缓冲内纯像素平移），完全不提交 VT、不触发任何会重置偏移的路径**；手势结束时把累积整行一次性提交 VT 并 rebase 回稳定态。绕开事件驱动的异步提交躯干，而非与之搏斗。

## 1. 核心不变式（违反即回到上次的 bug）

1. **单一所有权**：滚动激活期间（`isScrollGestureActive == true`），只有 display-link tick 能写 `viewport.visualOffsetY`。任何异步/输出/commit 路径**禁止**在此期间调用 `resetViewportStartRowKeepingVisualOffset()` 或 `viewport = ...`。
2. **滚动中不提交 VT**（方案 X 常态）：`|position| ≤ 缓冲深度`时，tick 不调 `commitViewportScroll`。→ 不产生异步 `finishQueuedViewportScroll` → 不会重置偏移。双写冲突从根消失。
3. **提交只在两处发生**：
   - (a) 手势结束（`engine.isActive == false`）→ 一次性对齐提交。
   - (b) 位移超过缓冲深度（长滚降级，少数）→ 提交到把 position 拉回缓冲内。
4. **prefersAsyncPresent 时序**：必须在**第一次 tick 之前**（`startScrollDisplayLink` 内）就设为 true，结束（`stopScrollDisplayLink`）设 false。不得依赖每帧 abort 来切换。
5. **偏移不再 clamp**（R1.1 已解 clamp 的前提下）：tick 可设多行偏移；`canRenderPixelScroll` 按缓冲深度守卫。

## 2. 状态与所有权模型

`PTYGridView` 新增/复用：

| 成员 | 类型 | 作用 |
|---|---|---|
| `smoothScrollEngine` | `SmoothScrollEngine` | 连续位置 + 惯性（纯逻辑，已存在于 0f84d42） |
| `scrollDisplayLink` | `CADisplayLink?` | 节拍源（macOS 14 `NSView.displayLink`） |
| `isScrollGestureActive` | `Bool` | 所有权闸：true 时禁止其他路径写 offset |
| `scrollActivityHandler` | `((Bool)->Void)?` | 通知 backend 切 `prefersAsyncPresent` |

`engine.position` 符号沿用 `visualOffsetY`：正=向上看历史（overscanTop），负=向下（overscanBottom）。

## 3. 数据流（时序精确）

### 3.1 输入（scrollWheel）
```
scrollWheel(event):
  alt-screen / no-frame / !smoothPixelScrollingEnabled → 老 processScroll 转发（不变）
  momentum 非空 → 丢弃（引擎自研惯性）
  began/changed → engine.addWheelInput(delta, phase, now); startScrollDisplayLink()
  ended/cancelled → engine.addWheelInput(0, .ended, now)   // 不停 link，让惯性跑
  discrete(鼠标滚轮) → engine.addDiscreteScroll(delta, now); startScrollDisplayLink()
```

### 3.2 startScrollDisplayLink（关键：一次性置位，无 thrash）
```
guard scrollDisplayLink == nil else { return }
isScrollGestureActive = true
scrollActivityHandler?(true)          // ← prefersAsyncPresent=true，先于首帧
link = displayLink(target:self, selector:#tick); link.add(.main, .common)
scrollDisplayLink = link
```

### 3.3 tick（每刷新一次；热路径，无 VT 往返）
```
tick(now):
  engine.tick(now)
  applyPosition(engine.position)
  if !engine.isActive { finishScrollGesture() }   // 惯性结束 → 对齐提交
```
```
applyPosition(pos):
  guard cellHeight>0
  depth = renderableDepth(forSign: pos)            // overscan行数×cellHeight（该方向）
  if depth<=0 { finishScrollGesture(); return }    // 该方向到边 → 结束
  if |pos| ≤ depth:                                // 常态：纯像素平移，不提交
      viewport = TerminalViewport(visualOffsetY: pos)
      needsDisplay = true
  else:                                            // 方案X降级：超缓冲长滚
      applyOverBufferScroll(pos, depth)
```

### 3.4 finishScrollGesture（结束，唯一常态提交点）
```
finishScrollGesture():
  isScrollGestureActive = false
  scrollDisplayLink?.invalidate(); scrollDisplayLink = nil
  scrollActivityHandler?(false)                    // prefersAsyncPresent=false
  rows = Int(engine.position / cellHeight)         // 整行部分，向零取整
  if rows != 0, viewportCanScrollHandler?(rows) != false {
      if commitViewportScroll(rowDelta: rows) {    // 异步；此刻已非 active，reset 无冲突
          engine.rebaseCommittedRows(rows, cellHeight)
      }
  }
  engine.reset()                                   // 停惯性，position 归 0
  // 提交回来后 finishQueuedViewportScroll 正常渲染（offset≈0），无双写
```

### 3.5 applyOverBufferScroll（方案X降级，少数）
```
excess = |pos| - depth*SAFE (SAFE≈0.9)
rows = ceil(excess/cellHeight) * sign(pos)
if viewportCanScrollHandler?(rows) == false { finishScrollGesture(); return }
commitViewportScroll(rows) 成功 → engine.rebaseCommittedRows(rows); viewport=offset(engine.position)
// 仅超一屏长滚触发；此路径滚动中有一次 VT 往返，可能轻微不完美（可接受）。
```

## 4. 保护不变式 1（禁止异步路径在滚动中重置 offset）

上次横跳的根：`finishQueuedViewportScroll`（registry）末尾 `resetViewportStartRowKeepingVisualOffset()` 把 offset 重置成 ≈0，与 tick 抢写。方案 X 常态下滚动中不提交 → 该路径不触发。但为**防御**（输出/其他 commit 仍可能在滚动中来），加闸：

- `PTYGridView.resetViewportStartRowKeepingVisualOffset()`：`guard !isScrollGestureActive else { return }`。
- `PTYGridView.viewport` 的其他外部写入点（输出渲染 `render(...)` 的 pinned reset 等）在 `isScrollGestureActive` 时跳过 offset 重置。
- 具体守卫点在实现时逐一核对：搜索所有写 `viewport = ` 的位置，滚动激活期只允许 tick 写。

## 5. 边缘 / 中断 / 清理

- **scrollback 到顶/底**：`applyPosition` 中 `depth<=0`（该方向无 overscan）→ `finishScrollGesture()`（不 abort thrash，一次干净结束）。
- **resetPixelScroll / 失焦 / alt-screen 切换 / pinned 输出**：调用统一的 `abortSmoothScroll()`：停 link、`scrollActivityHandler?(false)`、`isScrollGestureActive=false`、`engine.reset()`、`viewport=TerminalViewport()`。
- **viewDidMoveToWindow(window==nil)**：`abortSmoothScroll()`。
- `finishScrollGesture` 与 `abortSmoothScroll` 的区别：前者对齐提交后归位，后者直接丢弃（用于强制中断）。

## 6. 渲染侧（已就绪，仅需接线）

- `prefersAsyncPresent` + in-flight 信号量：R1.1 已在引擎实现（inert）。本步经 `scrollActivityHandler` 接线到 backend：`directView.scrollActivityHandler = { self.engine?.prefersAsyncPresent = $0 }`。
- 时序保证（不变式 4）：`startScrollDisplayLink` 先置 true 再加 link，故首帧 render 时已是 async。
- 大纹理 band composite（R1.1）：`viewport.visualOffsetY` = 多行 pos 时，composite 平移 `-overscanTop*ch + pos*scale` 已能正确选 band（R1.1 已验证多行偏移渲染）。

## 7. 平台

CADisplayLink `NSView.displayLink(target:selector:)` 需 macOS 14。提 `Package.swift .v14`、`README`（正文+badge）、`build-app-bundle.sh`（LSMinimumSystemVersion 14.0）。与本步同做。

## 8. 分步实施（每步 build+test+guard + release bundle 手测，按 CLAUDE.md 运行前必做清单）

1. **平台提 v14** + 接 `scrollActivityHandler`（backend）。build 绿。
2. **display-link 生命周期**：`scrollWheel` 喂引擎 + start/stop/abort/finish 骨架，tick 仅 `viewport=offset(pos)`（先不提交、不降级）。手测：缓冲内滚动是否 60fps 丝滑、`prefersAsyncPresent` 是否 true（日志）。
3. **finishScrollGesture 对齐提交** + `rebaseCommittedRows`。手测：松手后内容对齐、无跳、无双写（日志确认 position 不横跳）。
4. **不变式守卫**：`resetViewportStartRowKeepingVisualOffset` 等加 `isScrollGestureActive` 闸。手测:滚动中有输出(tail -f)不错乱。
5. **超缓冲降级** `applyOverBufferScroll`。手测：持续快速长滚不空白、可用。
6. **命中测试红线复验**：滚动中/后 选区/链接/⌘点击/IME 位置正确（`RenderedGridGeometry.translationY` 与 tick 设的 offset 同步——注意：tick 设 `visualOffsetY`，geometry 用 `drawTranslationY` 读同一 viewport，天然同步；但 clamp 已在 R1.1 保留，多行时需在本步解 clamp 并复验，见下）。
7. **解 clamp**（`visualScrollTranslationY` 去掉 ±cellHeight）+ `canRenderPixelScroll` 深度守卫。这两个 R1.1 回退时撤下了，本步随多行偏移重新加回并测。

## 9. 诚实的风险与降级

- **最大风险仍是所有权**：任何遗漏的 `viewport=`/reset 写入点在滚动中触发 → 横跳复现。第 4 步必须穷举所有写入点（grep `viewport = ` + `resetViewportStartRowKeepingVisualOffset` 调用者）。
- **惯性结束时机**：`isActive=false` 由引擎 `minInertiaVelocity` 阈值决定；若结束太突兀，调 `Config`。
- **超缓冲降级**（方案 X）：接受长滚有一次 VT 往返的轻微不完美；若手感差，未来做 R1.3 懒惰重居中（本 spec 不含）。
- **实时输出锚定**：滚动浏览历史时新输出的处理沿用现有 pinned 逻辑；第 4 步验证不冲突。
- 每步独立 commit，可单步 revert。失败即回到 R1.1（`6ca6c78`）干净基线。

## 10. 验收标准（全绿才算 R1.2 完成）
- 缓冲内滚动稳定 60/120fps（日志 `gapMs≈16.7/8.3`），`workMs<1ms`，无 committed=true 刷屏。
- position 单调不横跳（松手前）。
- 无空白、无闪烁、无撕裂。
- 边缘干净停住，不卡死、不 thrash。
- 命中测试红线全部正确。
- `seq`/打字/静止不受影响。
