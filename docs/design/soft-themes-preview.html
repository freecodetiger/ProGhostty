Soft Dark / Soft Light · 经考验色板评审稿

Soft Dark 按你在 Ghostty 里熟悉的那路气质改： 深色带一点蓝（不是 Nord 那种偏灰），接近 Atom One Dark / Ghostty / One Dark 蓝深气质，底在 #282C34 上再压一点 → #23272E。 Soft Light 仍用 Solarized Light。用户选整套预设，不拧单色。

Soft Dark 来源： 经典编辑器/终端深青蓝灰系 —— Ghostty / Atom One Dark 气质；底从常用 #282C34 再压到 #23272E，字色/注释仍用 One Dark 惯用对。
Soft Light 来源： Solarized Light。
可读性底线 · WCAG 1.4.3 （≥ 4.5:1 AA），可用 WebAIM 复核。
